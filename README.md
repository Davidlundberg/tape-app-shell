# Tape: app shell

Tape is a private practice app for speaking about financial markets out loud: learn, drill, then answer a question in 30 or 90 seconds and grade yourself against a model answer.

This repository holds only the installable web-app shell, which is published to GitHub Pages. **It contains no content.** The card deck loads at runtime after sign-in, from a database row that only its owner can read (row-level security). Progress stays on the device.

To install on a phone, open the Pages URL and choose "Add to Home Screen".
